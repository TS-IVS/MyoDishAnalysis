First steps (5 minutes)

          
    
            
  1. Open Automatic analysis. The raw folder is the folder that holds your recordings (.mdd), each with its log file next to it.
    2. 
            
  2. Click Show what would be analyzed. You get the list. Nothing is written.
    3. 
            
  3. Click Analyze new recordings now. The lines of the analysis appear while it runs. You can leave the page: the analysis goes on as long as the program runs.
    4. 
            
  4. Open Results. Every row is one channel of one recording. A colored note means that something deserves a second look. Click a row for the details, the course over the recording and the report.
    5. 
            
  5. For the traces themselves, copy the command of the row into MATLAB or a terminal. The desktop program opens at that place.
    6.

What the colored notes mean

          

          
Red: check the analysis

          
The numbers of this channel may be wrong. Look at the traces before you use them.

          
    
          
    Orange: sensor or chamber
    
          
    The hardware limits what this recording can say. The contractions are analyzed as usual, and nothing is corrected by calculation.
    
          
      
          
      Yellow: slice quality
      
          
      Possibly a weak slice, possibly the effect of a treatment. You decide.
      
          
        
          
        The rules in short
        
          
          
          
          The letters in brackets are the short codes of the result files and of the overview table of the report.
          
        
          
        
          
          
          Automatic analysis of a folder
          
          
            
            
          • What is analyzed: every recording of the raw folder and its subfolders that is new or has changed since its analysis. A recording that is still being written waits for a later analysis. Of recordings made in parallel, the main file is analyzed.
            • 
            
          • What you get: per recording a workbook with the results and one image per channel with the course over the recording, per experiment a report (PDF), and per analysis a short text report (list on the page Automatic analysis).
            • 
            
          • Earlier results stay, also after an update of the program or a change of the settings. The lines of the analysis say so when earlier recordings were analyzed differently.
            • 
            
          • Another raw folder: recordings are known by their path below the raw folder. From a folder one level up or down all of them would count as new, so the page asks before it analyzes from another raw folder than the last time. Look at the list first.
            • 
            
          • Every day without a click: start the watcher on a schedule in a terminal, e.g. mda-watch RAW RESULTS --schedule "daily 10:00", or in MATLAB with MyoDishAnalysisWatch. This page shows those results as well, and tells you when such a watcher is at work.
            • 
          
          
        
          
        
          
          
          Settings
          
          
            
            
          • Basics are the settings people change, in plain words. Expert holds every other setting of the analysis. Most analyses never need them.
            • 
            
          • A changed setting is marked, with its standard value and a link that sets it back. Nothing is used before you click Save.
            • 
            
          • The settings are used by the analyses started from this page. Results of earlier analyses keep the settings they were made with.
            • 
            
          • Take the settings of the newest analysis fills the page with the settings of the recording analyzed last, so that an experiment goes on with the settings it began with.
            • 
            
          • The settings are a file in the results folder (). Other programs use it with the option settings: mda-watch RAW RESULTS --settings FILE, in MATLAB MyoDishAnalysisWatch(raw, results, 'settings', file).
            • 
            
          • Settings of one recording (a threshold set by hand, the zero force, a reference beat) belong to the desktop program.
            • 
          
          
        
          
        
          
          
          Looking at a recording
          
          
          The traces of a recording with the detected contractions are shown by the desktop program for now. Select a row on the page Results and copy one of the two commands: the first for MATLAB, the second for a terminal with the Python version. The program opens the recording at the channel and the time window of the row.
          
          
          The desktop program runs on the computer that holds the data.
          
        
          
        
          
          
          Who can reach this page
          
          
          
          
          The page has no login. Started with --host 0.0.0.0, every computer that reaches this one can read the results and start an analysis: use that inside a trusted network only, never on a computer that is reachable from the internet.
          
          
          The page loads nothing from the internet, and it serves files of the results folder only.
